## 不确定性与取舍

- 铜钵河原报道“均摊坝／均滩坝”异写，页面采用“下游断面”并提供注释。
- 2025年生态环境部长期水质总结与2024年单次异常，不按同一时间尺度拼接；不作“从无异常”结论。
- 2024其他报道出现不同感知点数量；本页选择2024-04与2025-10清晰口径，不拼成连续增长曲线，不把不同发现/处置时间指标混用。
- AI预测精度报道有不同场景与表达，本原型保留能力层面，不将精度作为统一性能指标。
- 临江河有公开氟化物事件候选，但溯源机制与蒲河重合；龙河/龙溪河可扩展，但本轮聚焦3个互补案例。未入选不等于无材料。
- 单案例叙事不能识别AI的独立因果贡献；制度、基础设施与人员执行同样参与。
